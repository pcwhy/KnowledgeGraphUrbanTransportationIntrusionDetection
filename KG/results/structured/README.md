# Structured Results

This folder is intentionally empty in the GitHub export.

The files under `results/structured/` are generated locally when you run the
experiment scripts in:

- `experiments/synthetic/`
- `experiments/city/`
- `experiments/analysis/`

Typical generated subfolders are:

- `results/structured/synthetic/`
- `results/structured/city/`
- `results/structured/overhead/`
- `results/structured/assets/`

Run the experiments first, then inspect the generated CSV and JSON outputs
here.
